# Dashboard Bengkel STEM AI — GitHub Pages

Versi ini sudah siap dibina dan boleh terus dimuat naik ke GitHub Pages.

- Pendaftaran turut dikira sebagai kehadiran.
- Menu dan borang Kehadiran berasingan telah dibuang.
- Bahagian Laporan dikekalkan untuk fasa pelaporan selepas bengkel.
- Tidak memerlukan Netlify, Vercel atau Environment Variables.

## Muat naik

1. Cipta repository GitHub baharu dan pilih **Public**.
2. Pilih **Add file > Upload files**.
3. Upload semua kandungan folder ini sehingga `index.html` berada di halaman utama repository.
4. Tekan **Commit changes**.

## Aktifkan GitHub Pages

1. Buka **Settings > Pages**.
2. Pilih **Deploy from a branch**.
3. Pilih branch **main** dan folder **/(root)**.
4. Tekan **Save**.

Folder `source-code` disertakan untuk rujukan dan suntingan pada masa hadapan.
