# Dashboard Bengkel STEM AI — GitHub Pages

Pakej ini sudah siap dibina. Tidak perlu Netlify, Vercel, Environment Variables, `npm install` atau GitHub Actions.

## Muat naik

1. Cipta repository GitHub baharu dan pilih **Public**.
2. Pilih **Add file > Upload files**.
3. Upload **semua kandungan dalam folder ini** sehingga `index.html` berada di halaman utama repository.
4. Tekan **Commit changes**.

## Aktifkan GitHub Pages

1. Buka **Settings > Pages** pada repository.
2. Di bawah **Build and deployment**, pilih **Deploy from a branch**.
3. Pilih branch **main** dan folder **/(root)**.
4. Tekan **Save**.
5. Tunggu beberapa minit sehingga GitHub memaparkan pautan website.

Dashboard membaca dan menghantar data terus melalui Google Apps Script yang telah dipasang. Google Sheet kekal Private.

Folder `source-code` ialah salinan kod asal untuk rujukan atau suntingan pada masa hadapan. GitHub Pages menggunakan `index.html` dan folder `assets` di bahagian utama repository.
